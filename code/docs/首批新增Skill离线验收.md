## 对过去付费故障的影响

- **选卡与实际交付。** 修复了选中并算完之后逐问报告仍待答的交接。工具回执现在按方法传给对应子问，单句复合问也能展示有据的计算和未决部分。AZZ 存档里的财政年度与自然年不同，分部卡用发行人披露的财年、季度和结束日期把原表结果绑定到所问期间。
- **重复取证。** Cintas 的真实最后一次读表只返回已覆盖的原文。在旧存档中，每条工具回执缺少范围版本，测试从紧随其后的两次真实 Planner 输入还原该版本。复测在单选和附加另一张卡时都能识别这次重读。带新增金额的对照允许继续。另用遮证后的英特尔公告故意让 Planner 连做两次相同核对，第二次缺口、来源与数值都未变，控制器在启用故障即停的配置下返回 repeated_retrieval_without_new_evidence，一共两个工具动作。[故障注入与真实回放结果](../../../work/skill_integration_wave1/loop-results.json)
- **误选的额外卡。** 对本地选卡器误选的四道旧题，将实际选卡结果交回正式分析工具。新增卡四次均标为不适用，产生零个无关计算。AZZ 的现金问题同时选中了现金流和分部卡，现金流方法仍产出从半年累计扣回单季的差额 44,391 千美元。在真正独立的其他子问仍未答到时，控制器继续保留该子问。[按实际选卡重放的工具回执](../../../work/skill_integration_wave1/routed-tool-receipts.json)
- **旧题回归。** SFM 真实第二问问的是两期营业利润率相差多少个百分点，离线入口继续沿原方法得到 +1.25 个百分点。APOG 原二问继续给出净利同比减少 126.9 万美元，其中税费变化抵消 373.3 万美元。遮原因段后保留数字和未归因部分。这两题沿用了原有能力，不能把数值归功于新卡。
- **仍待验证。** Graco 原追问解释分部销售增长、利润率下降，旧的付费首稿漏掉了收购业务亏损的附注。新增分部卡做的是合并数调节，本轮没有证明这个披露覆盖问题改善。GPT 的首稿命中率、Critic 是否漏审、实际改稿次数和费用也需要另做付费对照。
