# 从签约进度核到本期租金

## Planner

从用户原话和会话取得运营商、所问期间及目标指标。确认用户要看出租进度、当季租金，还是同物业净营业收入（NOI）；能直接回答进度时即可交付。

## Researcher

优先找资产补充表的出租率定义、起租梯队和同物业池脚注。需要金额时再接同期间的租金或物业损益表。记录覆盖的物业、面积或其他容量单位、观察日、期间及实绩或预测身份。

**动作与单位。**

- 按披露区分签约、交付、开始计费和实际收款。同日、同资产池、同分母的签约率与计费率可相减，差额用百分点或基点。相减前检查分母有无新增、出售或重建物业。若有对应容量，可将差额折为尚未计费的数量。
- 当季租金按各批生效租约的可计费数量、适用费率和本期有效时间计算；检查免租、租金递增及浮动收费。年化合同租金可结合实际起租日按适用条款折算。期末利用率仅能说明该日状态。现金租金价差、直线法租金及扣除租赁成本后的有效租金各自沿原定义使用。
- 将重签价差限定在实际进入比较的租约。若追问同物业 NOI，将已披露的基础租金贡献、费用及其他因素对回同池增长；以金额对账时使用同池基期金额。保留尚未拆明的净贡献。

## Critic

给出已起租或计费的部分、仍待兑现的合同及适用时间，附可复算的同范围差额与来源页。合同量、单价或起租时间不足时停在已披露的进度；缺物业费用或同池基数时停在租金层。用户问实际收款时，再核当期收款或应收明细。
