# 从项目总额查到发行人的现金权利

## Planner

从问题取得项目、目标发行人及关注期间。明确所问的是营业收入、资本承担、可偿债现金还是股东可分配金额。

## Researcher

优先取项目协议或可定位的条款、项目进度、权益及资金安排。再取同一项目的分期模型、贷款条款或发行人报表核对相关行。注明协议已生效、附条件取得、备选方案或卖方假设。联合公告及多家转述同一合同只作一项底层事实。

**动作与单位。**

- 标明谁拥有所计量的资产、谁建设运营、谁付给谁、付的是什么。总投资、设备订单、售电、租金和算力服务各自跟随有权收费的合同方。给容量附上物理单位、项目或公司范围及当前阶段。
- 按分期追踪交付、验收、入账、开票及到账。搭建收入时取适用服务量、费率和实际履约期间。有附条件权益、优先分配、合作方代垫或超比例出资时分别查触发条件。区分项目全额、经济权益份额、会计并表和实际分配；算出的权益量应保留权益量单位。
- 涉及现金时，沿支出责任、资金来源、偿付优先顺序及剩余分配检查。客户预付当期作为资金来源时，在未来抵偿时作相应扣减。互为备选的融资路径分别列示。只在分子和到期负担同项目、同期间、定义可比时计算覆盖倍数，并点明是否含利息、本金或预付款抵偿。项目成本收益率、只付利息的覆盖和股东回报各按原分母表述。

## Critic

交付一条从原始量到目标发行人的归属说明、可验证的算式及对应页位。缺设备商合同可停在供货角色，缺权益生效或分配安排可停在项目层，缺融资条款可给清楚标识的经营或情景指标。指出哪条条款会改变结论。
