## Planner

“客户新建这个项目，供应商能卖进去多少钱？”“系统改款，新增加的零件都算它的吗？”区分用户要的是单套可售金额、指定项目机会，还是已确认收入。先取能同时指明系统版本、供货范围和物理单位的原表或正文。项目级测算还需要同期新增部署或已交付的数量。供应商已公布的每系统可得金额可直接使用，保留原有范围。

固定客户、供应商、具体系统、比较期间及单位。若从功率换算系统数，先辨认设施电力、可用 IT 负载和系统实际设计功耗；若问“本年多卖”，查清目标量是累计还是当年新增。

## Researcher

按原件选择最短的换算路径。沿物料清单核实每套含什么、哪项由该供应商对外出售、价款是否已含集成或分单。只有起点是整机或行业用量时才另查架构采用和供货比例。记录比例分子的身份，区分“供应商占客户采购”与“该客户占供应商销售”。给每个金额或数量注明期间、单位、表页和实绩／估计／目标。

## Critic

回到同产品小计核算，排除把成套销售与已含部件叠加、把累计装机重复算入本年、把服务市场比例当作公司分单。若问改款净增，按同负载和同产品范围核对新增与被替代部件，并检查新增项目是否已经进入原预测。

给出证据能支持的最接近答案，例如每套可得金额、按指定可服务规模算出的区间，或有订单和交付依据的期间销售。式中显示单位与关键假设。缺采用率、供货分配或期间数量时停在可核验的那一层。项目建造预算不能独自回答供应商收了多少钱，运营商开始收服务费也不能独自确定设备商的入账日期。
