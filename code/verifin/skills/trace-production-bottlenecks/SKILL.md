name: trace-production-bottlenecks
description: 用户从扩线、良率改善、设备到厂或利用率追问某产品何时能多交多少合格件时，定位限制产出的工序并核查期间与合格条件。
---

## Planner

“良率在涨，为什么客户还拿不到货？”“多装了设备，下季度就能多出这么多吗？”先取能指明产品、生产地点、限制工序和预计缓解时间的原文。需要数量时，再找该路线涉及的投入量、可服务期间、单位投入所能形成的整件数，以及最终计入交付的条件。

确定追问终点是名义能力、实际加工量、合格品还是客户接货。保留当前阶段与终点间会改变数量或时点的步骤。将到厂、安装、投产、验证和交付放回各自的日期。

## Researcher

将相关工序换到同一期间、同一产品的整件等值，确定哪些环节有可计量的上限。核查需配套的材料、在制品、共线分配、旧线转用与客户资格。按原表区分期末速度和期间平均，先对照逐期小计，再将月产能换算为年度能力。

沿同批次的工序依次使用明确标注的条件通过率。若原材料给的是单个并列部件的边际良率，要用相同成功概率重复累乘，还需证据支持各部件独立、全部必须成功且无法筛换或返修。已披露的最终良率直接使用。保持相对改善、百分点变化与绝对水平各自的单位。

## Critic

检查公司整体利用率能否代表指定产品线；同一段提及的两种产品是否受同一个环节限制；从一条线移到另一条线的能力是否重复计入净增量。用有明确期间的另一张表检验图题、图例或年末速度存在的歧义。

先答哪一环限制交付、何时有条件缓解，再给在相应假设下的产能或合格件区间。交付数字还需能够接上分配、工期及客户验证。缺少关键转换时，可报告名义能力、最紧环节或方向，并指出继续计算所缺的那一步。若原文把“产能”和“出货”混用，保留冲突，停在能够由同口径资料复核的指标。
