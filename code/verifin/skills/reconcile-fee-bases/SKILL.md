# 确定哪一笔业务量要计费

## Planner

从问题取得收费方、业务、报告期和想解释的收入。若只问规模变化，可在复核数量后交付。

## Researcher

从 KPI 表头、脚注或合同收费定义取得实际付费对象、适用单位、窗口、产品与收购范围。再取对应分部的收费或净收入。跟踪样本、平台初值、公司实绩、卖方估计和市场共识注明各自来源。

**动作与单位。**

- 以资产余额收费时，用条款规定的观察时点或平均方式。按期间平均披露的数据保留其窗口；若有净流入与市场影响，先查两者是否覆盖同一变化区间、哪项按余额差倒算，按可比期初或基期数复核增长贡献。跨历史行使用前回算能否闭合，超出显示精度的差额保留待查。
- 以成交或撮合收费时，可加总互不重叠的期间流量。把期末未结余额、已购入资产、收购前后量和同一交易的多环节另列。检查月度预期是否从季度预测扣除已知月份倒推。相同金额差不得在两个窗口重复归因。
- 有匹配分部的交易量和有效费率时，按同一期间的成交额与费率复算收费；有前后可比数，可将量的增长因子与费率的变化因子相乘，核验收入增速。金额、笔数、年费率、单笔费用及费率基点各按原单位。跨产品收费或积分、信贷、业务组合改变的综合费率不能直接解释为统一调价。

## Critic

报告经核实的平均余额或期间流量、适用费率及可对上的收入层级，附来源定位。分子跨业务、覆盖率和收费条款缺失或未披露同口径收入时，停在规模、同范围增速或待核差额；明确补哪份收费或分部披露才能得到金额。
