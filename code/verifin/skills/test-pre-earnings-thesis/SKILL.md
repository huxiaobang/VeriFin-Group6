## Planner

输入是待检验的原话、所属财季、事件及需要比较的预测者。先找事件前已发表的原稿，记录发布日期和实际公布日。只从前稿写下当时预计的结果、已纳入的事项，以及原解释成立时可观察的驱动。没有事前原稿时，只能核对后稿回述的旧预测。

## Researcher

在公布后的文件中，以同一业务、期间、单位和定义的实际行对照事前预测，报告有符号偏差。再比较原解释依赖的驱动，即使总体命中也保留驱动判断的误差。跨期活动需核其在预测日是否已知、影响哪期、金额由谁测算。

若追问下一季，把新发公司指引、作者对指引的事前预想、作者自己的盈利预测和带日期的市场共识分别对齐。只有能核对同一覆盖团队的旧、新模型，才写该团队改了哪期、哪项预测。其他团队可提供实际值，并保留实际值的原始披露来源。

## Critic

分别交付当时的判断、事后偏差、可验证的驱动及有据可查的模型修订。每个差额保留比较对象和日期。若事件前后口径不可比，只交付两边各自可证的事实。最终指标和解释同方向仍不能量化因果；要归因，须有范围匹配的归因披露或足以区分该原因与同期其他变化的证据。
