# Scripted integration example

This folder was generated by `python3 -m scripts.demo_replay`. The financial sources and calculations are real; model choices, synthesis and critique are explicitly scripted test fixtures. No live model or network request was used. Supported labels reflect the fixture protocol, not measured semantic accuracy.

- [report.md](report.md): inspectable report with source locations and formula.
- [report.json](report.json): saved report structure.
- [evidence.csv](evidence.csv), [calculations.csv](calculations.csv): export formats.
- [result.json](result.json): calls, source values and reopen/reuse check.

The report is from the second turn after reopening the database. The database is excluded from the release; the command above creates your own local copy. This is not a held-out evaluation case or gold annotation.
