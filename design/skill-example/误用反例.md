# 哪些结论应退回

| 见到的说法 | 用原件核对 | 可支持的答复 |
|---|---|---|
| “英特尔应付多了 3,978 百万美元，今年因此多留同额经营现金。” | 年度经营现金流该行是 +634，余额代理多出 3,344。 | 最多写明 3,344 的差额待解释。设备或并购相关现金在其他分类里出现，本身不能证明导致此差额。[原件](公开原件/INTC-20250130.html) |
| “英特尔第四季经营现金流 +3,165，因此全年应付调节 +634 也属于第四季。” | 季度总额和年度明细来自不同期间列。 | 可答季度总额；本原件缺该季应付现金调节。年度值按四等分也没有披露依据。[原件](公开原件/INTC-20250130.html) |
| “从英特尔归母亏损开始加回全部项目，经营现金为 8,765。” | 归母 −18,756 与合并 −19,233 相差 477。 | 用现金流表的合并起点重算为 8,288。仅有归母亏损时需先找到归属对账。[原件](公开原件/INTC-20250130.html) |
| “微软应收在半年释放 8,059，说明第二季也在释放。” | 同张现金流表三个月和六个月栏方向相反。 | 第二季 −5,978；半年 +8,059；第一季推算 +14,037。余额变化与实际收款金额仍应分别陈述。[原件](../../VeriFin_Code/data/replay/snapshots/msft_fy25q2_ir.html) |
| “同一期间应收余额净降 8,736，所以微软上半年应收现金行必定也是 +8,736。” | 同期现金流原行为 +8,059，相差 677。 | 表内能够确认金额与方向；缺进一步披露时，差额原因保留未知。期限正确也不能使余额代理自动等于现金行。[原件](../../VeriFin_Code/data/replay/snapshots/msft_fy25q2_ir.html) |
