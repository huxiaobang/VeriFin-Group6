# 两家公司按公告原表复算｜验收侧

**英特尔 2024 财年。** 全年合并净亏损 19,233 百万美元，资产负债变动之前的调节合计 +26,418，经营性资产负债变动合计 +1,103，经营现金流为 **+8,288**。上年三项分别为 +1,675、+10,365、−569，合计 +11,471。2024 年前组主要包括折旧 +9,951、递延税 +6,132、重组及其他费用 +3,491 和股票薪酬 +3,410 等；这是损益到现金的调节，不能将其金额解释成现金收入。若从归母亏损 −18,756 出发，会多算 477，恰为合并表另列的非控股权益亏损的绝对值。金额均为百万美元。[利润表及现金流量表](公开原件/INTC-20250130.html)

**英特尔应付账款与第四季。** 发行人全年现金流行直接给出应付账款影响 **+634**。同期资产负债表从 8,578 增至 12,556，余额增长 3,978，比报告现金影响高 3,344。现有两张表足以定出差额，不能把 3,344 全归给设备购置、并购、汇兑或某一供应商。第四季经营现金流总额在补充表为 **+3,165**；本次原件的间接法明细只有全年，不能从 +634 分出第四季应付款影响。若追加同口径九个月现金流明细，可以再求差。[年度经营现金流及补充调节](公开原件/INTC-20250130.html)

**微软 FY2025 第二季。** 截至 2024-12-31 的三个月，合并净利 24,108，加资产负债变动之前的调节 9,734，再计经营性资产负债变动 −11,551，得 **22,291**。经营现金流低于净利 1,817。上年同季为 21,870 + 7,283 − 10,300 = **18,853**，低于净利 3,017。本季资产负债变动中，应收 −5,978、未赚收入 −6,338、所得税 −3,395；应付 +958、存货 +711、其他流动负债 +3,217 等部分抵销，逐行详见计算明细。[发行人现金流量表](../../VeriFin_Code/data/replay/snapshots/msft_fy25q2_ir.html) · [所有原表行](原件复算.json)

**微软应收及半年。** 本季应收对经营现金流影响 **−5,978**，上半年累计为 **+8,059**。在相同财年和口径下，上半年减第二季可得第一季 **+14,037**；第一季释放的大于第二季占用的，半年仍为净释放。上半年完整桥为 48,775 + 18,391 − 10,695 = **56,471**，上年半年为 44,161 + 13,157 − 7,882 = **49,436**。资产负债表两个期末对应半年，净应收从 56,924 降至 48,188，按资产下降释放现金的简化估算为 +8,736，实际调节少 677。现有两表没有分解这 677，也没有给出“客户本季实际回款总额”。[发行人资产负债表及现金流量表](../../VeriFin_Code/data/replay/snapshots/msft_fy25q2_ir.html)
