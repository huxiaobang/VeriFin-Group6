# 从净利润核到经营现金流

## Planner

用户问“赚的钱为何没变成现金”“应收到底占用了多少钱”“亏损当年为什么经营现金流仍是正的”时，先确定需要回答的是合并经营现金流、单项对现金的调节，还是一笔实际收付款。标出财务期间、合并范围、单位及可用披露截止时刻。优先定位同一期间的间接法现金流明细和对应资产负债表。若报表首页只有季度经营现金流总额，查明细列的期间；不能直接把年度调节拆进季度。

## Researcher

从现金流表自己的净利润行出发，保留公司显示的正负号和项目分组。将经营性资产负债变动之前的各项调整求和，将经营性资产负债的现金影响另求和，检查“净利＋两组调整＝经营现金流”。合计行只作对账。公司有归属非控股权益、折旧减值、所得税或重组调节时，保留原行名称和口径。用户追问某项时，取该项现金流行，并在同期间资产负债表计算有符号的余额变动作为交叉检查。两者有差额时记录待解释金额，查有无对应附注。各项记录原件、发布日期、两层表头、行名、单位和算式。

## Critic

先验合并利润起点和两个期间端点，再独立复算桥接残差。股票薪酬、递延税及账面减值的加回不能直接证明收到该笔现金。应收或应付行反映对经营现金流的净影响，推断客户实际付款、供应商实际收款还需要相应交易披露。季度只有总额时，仅报告总额；有同一财年的相邻累计行、同一合并范围及会计口径时才能差分。余额代理与现金行无法对上且缺少相应附注时，停在可辨明的差额。研报模型中标作估计或旧预测的列只用于形成问题。
