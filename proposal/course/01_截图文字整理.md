## 图 1：Assessment: Group Project（COMP7608B · Lecture 1，07）

WHAT COUNTS AS A PROJECT?

**Build a working agentic application and defend its design.**

- Start with a user problem and clear motivation
- Propose a stack; identify risks and alternatives
- Evaluate quality, reliability, latency, or cost
- Submit runnable code and explain limitations

POSSIBLE DIRECTIONS

- financial-news research assistant
- domain RAG with source verification
- data-analysis and visualization agent
- coding, testing or support workflow
- personal or organizational knowledge assistant

**Benchmarking should support a design decision—for example, retrieval quality, latency, cost or tool-use reliability.**

## 图 3：AI assistance and ownership（COMP7608B · Lecture 1，08）

PERMITTED ASSISTANCE

- AI tools and open-source libraries allowed
- Try guided exercises yourself first
- Explain your code and architecture choices

WHAT IS NOT ACCEPTABLE

1. Submitting another group's work or a complete copied project as your own.
2. Presenting code whose architecture and behavior you cannot explain.
3. Hiding external sources, datasets, generated content or major dependencies.

The presentation may include design questions or a live modification. If ownership is not demonstrated, marks may be deducted.
